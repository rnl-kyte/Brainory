**Name:**  
Brainory – Student Study Tracker & Journal

---

**Description:**

Brainory is a mobile‑friendly web application that helps students track their study time, organize lessons by subject, and monitor academic progress through visual graphs and quizzes. It works entirely **offline** – no internet connection required.

**Background:** Based on a survey of 40 college students:
- 40% struggled with procrastination
- 37.5% often forgot what they studied
- 35% had no time awareness
- 52.9% were not confident tracking their progress

**Key differentiating factors:**
- Fully offline (no server, no internet needed)
- True/False quizzes with instant feedback
- Calendar reminders (type any time + AM/PM)
- No ads, no tracking, completely free

**Installation:**

**Option A: Install APK on Android Phone**  
1. Download `Brainory.apk` from this repository (see Releases or Actions tab).  
2. On your Android phone, go to Settings → Security (or Privacy).  
3. Enable "Install from unknown sources" (temporary).  
4. Open the APK file → tap Install.  
5. Open the Brainory app.

*Requirements: Android 7.0 (API 24) or higher.*

**Option B: Run as Web App (Any Browser)**  
1. Download all HTML files from this repository.  
2. Extract to a folder.  
3. Open `index.html` in Chrome (or any modern browser).  
4. No server needed – works offline.

---

**Usage – Quick Start**

1. Sign up using any email and password (stored locally).  
2. Create a note – add subject, topic, and content.  
3. View lessons – notes are automatically grouped by subject.  
4. Take a quiz – select a subject and topic → answer True/False → see score.  
5. Set a reminder – pick a date, type any time (e.g., 9:30), choose AM/PM.

**Example:** 
```
1. Open the app → Splash screen → Onboarding → Login
2. Go to Notes → Subject: "IT 324", Topic: "Cyber Sex"
   Content: "RA 10175 defines cybersex as..."
3. Save → Go to Lessons → expand IT 324 → view your note
4. Go to Quiz → choose "Cyber Sex" → answer questions
5. Your score is displayed at the end
```

**Features**

| Feature | Description |
|---------|-------------|
| Splash Screen & Onboarding | Gradient animation with 3-slide introduction |
| User Authentication | Local sign‑up / login (localStorage) |
| Dashboard | Daily study stats, dynamic subjects, graph, mini calendar, recent activity |
| Notes | Subject + topic + content notes |
| Lessons Page | Groups notes by subject. Expand, edit, or archive |
| Quizzes | True/False quiz with feedback and score (IT324 topics) |
| Schedule & Reminders | Month calendar, pick a date, type any time + AM/PM |
| Profile & Stats | User info, avatar upload, edit username/password, study statistics |
| Archive | Restore archived subjects |
| Settings | Font size, export data (JSON), clear all data, privacy policy |
| Notifications | Sample feed with filters (All, Unread, Study, Reminders) |
| Offline First | All features work without internet |
